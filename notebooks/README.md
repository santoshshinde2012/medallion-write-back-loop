# Notebooks

`write_back_loop_databricks.py` — the write-back loop expressed against Delta tables in a
Databricks workspace (import as a notebook, run cell by cell). **Illustrative**: adapt
catalog/schema names; the tested, CI-run implementation is `src/medallion_write_back/`.
This continues the heritage of the previous version of this repo
([medallion-architecture-databrics](https://github.com/santoshshinde2012/medallion-architecture-databrics)),
which was notebooks-first.
